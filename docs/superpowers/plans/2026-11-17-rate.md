> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add an accessible compact rating component matching the requested Ant Design feature set and mtone styling.
**Architecture:** Native React span slider with layered characters, controlled/uncontrolled values, pointer preview and step keyboard interaction. Standalone rate.tsx and rate.css; reuse existing locale and utility helpers.
**Tech Stack:** React 19, TypeScript, lucide-react, Vitest/Testing Library, Playwright.
**Spec:** docs/superpowers/specs/2026-11-17-rate-design.md
