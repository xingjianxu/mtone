# Table Implementation Plan

> For agentic workers: execute the plan task-by-task with tests and independent review.

**Goal:** Expand mtone Table to the Ant Design Table capability set without changing existing consumer behavior.
**Architecture:** unstyled rc table engine plus mtone state, controls, theme and compatibility adapters.
**Tech Stack:** React 19, TypeScript, @rc-component/table 1.12.0, Vitest, Playwright.
**Spec:** ../specs/2026-11-16-table-design.md

## Global Constraints
- Retain legacy onChange(state), data/selection/filter/sort aliases and pagination=false default.
- Preserve numeric keys, controlled null sorting, loading semantics and inline filterable inputs.
- Keep compact neutral mtone styles, locale/density/dark tokens.
- Sync catalog and generated llms; never publish npm without explicit authorization.

## Review Focus
- Controlled changes never override externally provided state.
- Selection across pages and disabled/tree nodes is coherent.
- Virtual rows with expansions/spans/fixed columns remain aligned.
- Legacy and modern aliases have deterministic documented priority.
- Filter/popover dismissal and keyboard/focus work reliably.
