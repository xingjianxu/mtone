# Fieldset 实现计划

目标：新增 mtone 风格的语义表单分组，不兼容 Mantine API，不改变现有表单校验协议。

1. 新增 FieldsetProps 与原生 fieldset/legend，提供 default/filled/unstyled、radius、原生属性与 ref。
2. 用内部 React context 传播 disabled 至本库表单控件，穿过包装组件和 Portal；保留首个 legend 的原生豁免和嵌套祖先禁用。
3. 测试原生语义、变体、ref、禁用继承、动态开关、弹层关闭、值保留与 legend 例外。
4. 添加独立文档 demo、catalog/reference，生成 llms.txt。
5. 执行类型检查、完整单元测试、文档构建、npm 包烟测；完成独立审查，不自行合并/发布。

实现选择：仅原生 fieldset 不足以阻止 portaled 与非原生控件的行为；采用单一内部 disabled hook，避免递归克隆 children（不能覆盖用户包装组件）。第三方/非表单交互控件不自动接入，文档明确。
