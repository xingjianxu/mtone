**Goal:** Add practical Progress variants while preserving existing appearance.
**Architecture:** Extract Progress from basic.tsx into progress.tsx; retain re-exports. CSS line tracks and SVG circle tracks share normalized state.
**Tech Stack:** React, TypeScript, CSS, SVG, Vitest, Playwright.
**Spec:** docs/superpowers/specs/2026-11-18-progress-design.md

## Global Constraints
No new dependencies; value/label stay supported; default line height 5px and information hidden; docs/catalog/llms synchronized.

## Review Focus
- NaN, infinities and negative dimensions never generate invalid geometry.
- 0/100 values show no start dot/full completion correctly.
- Many steps are bounded to avoid runaway rendering.
- Custom formatted nodes preserve accessible percentage.
- Multiple gradients have unique IDs and reduced motion is respected.
