**Architecture:** Native textarea, pure search/insertion helpers, caret mirror and React popup. No new runtime dependencies.
**Tech Stack:** TypeScript, React, Vitest/Testing Library, Playwright.
**Spec:** ../specs/2026-11-16-mentions-design.md

## Global Constraints
- Grey candidate highlight; public API and catalog/llms stay synchronized.

## Review Focus
- Editing a token in the middle preserves suffix and caret.
- Controlled refusal never shows candidates for unaccepted text.
- IME Enter never selects a candidate.
- Late async options cannot leave an invalid active descendant.
- Scroll/resize/portal geometry stays within the viewport.
