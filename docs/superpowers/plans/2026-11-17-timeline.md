# Timeline Implementation Plan

Goal: chronological display with mtone styling, without new dependencies.
Architecture: semantic ordered list; CSS grid handles vertical title/content alignment and horizontally scrolling tracks. Items remain in DOM reading order; reverse makes a copied reversed array. Custom nodes remain React content, not raw HTML.

- [ ] Test items, titles, aliases, reverse, pending, custom icons, loading, modes, attributes/ref and immutability before implementation.
- [ ] Implement timeline.tsx and scoped timeline.css, export from index and import CSS.
- [ ] Add Chinese catalog/demo, generated llms, real-package smoke, responsive three-browser fixtures and CI.
- [ ] Run full unit/type/build/package checks; independently review. Browser unavailability must be reported, not counted as a pass.

Defaults: vertical/start/outlined, neutral marker. titleSpan is a CSS length (number means px); unlike Ant's grid span. Horizontal mode scrolls inside its container, not the page. Semantic classNames/styles objects are supported. No animation scheduling or event editing.
