# Tabs enhancement
Preserve items/value/defaultValue/onValueChange and the neutral line style. Extend the existing Base UI keyboard/ARIA implementation rather than adding a second component library or custom focus machinery. Add line/card/editable-card, sizes, top/bottom/start/end, icon, centered, extraStart/extraEnd, add/remove callbacks, native overflow scrolling plus menu, optional reorder callbacks, and explicit panel lifecycle controls. Default hidden-panel destruction preserves current behavior. Caller owns items and ordering; no automatic destructive edits. Native drag is optional, with keyboard move shortcuts. No arbitrary tab-bar renderer or animation engine promised.
