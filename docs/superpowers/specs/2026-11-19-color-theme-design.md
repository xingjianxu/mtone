# mtone 颜色主题

用户确认组件库和文档站都支持浅色、深色、跟随系统。仅调整网站较快，但应用无法复用，因此选用库级语义色与主题作用域，网站复用。现有应用未选择主题时保持浅色和既有用法。

库扩展 MtoneProvider 和 MtoneScope 的 theme，接受 light、dark、system；系统模式利用浏览器颜色偏好实时响应。浮层沿用触发上下文并继承主题，独立/嵌套作用域不应相互影响。颜色保留 mtone 紧凑中性风格、辨认度及现有浅色值，HTML 原生控件匹配模式。

文档站和独立示例默认跟随系统、提供可操作的三态切换，记住手动选择且可恢复系统模式。主题页记录 API。验证自动、手动、重载和浮层、浅色兼容性。不发布 npm。
