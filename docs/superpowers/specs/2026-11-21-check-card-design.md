# CheckCard
Standalone selectable card and a group for single or multiple selection. Keep the existing Card for content and CardGroup for layout. Combining with CardGroup inside CheckCard.Group gives responsive arrangement without adding another grid API.
Native checkbox/radio semantics, keyboard and form behavior; independently controlled or default selections. The selection surface has a title, optional description/avatar/cover and a sibling action area that never selects the card. Provide disabled/loading, size and border styling using mtone theme tokens. Do not copy another library’s API or add dependencies.
The docs show standalone, group modes, rich content, state and composition, with synchronized generated reference. Ship on its own branch, no master merge or npm.
