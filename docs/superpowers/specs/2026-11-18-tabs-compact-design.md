# Tabs 紧凑卡片样式

用户已批准效果图：默认外框总高 28px，14px 文字及图标，图文间距 6px，保留中性灰与细边框，顶部圆角、底部两个直角。

实现选择：限定 card/editable-card，同一排无论是否有图标都保持相同高度，避免按 icon 条件切换产生参差；line 不变。small/medium/large 外框为 24/28/32px，保留字号梯度 12/14/15px，图标 14px。四个方向均保留图中明确要求的物理角形。使用 border-box 外框和无纵向 padding 的按钮，不改 API、行为、其他控件或工作流。根节点重置尺寸变量防止嵌套继承。默认卡片尺寸与 Input/Select 对齐，不随密度令牌变化。

验证：先增加两个 CSS 合约测试观察失败，再实现并测试；扩展现有三浏览器脚本覆盖 2种卡片×3尺寸×4方向、图标/纯文字/禁用项、悬停圆角及 line/Input 隔离。执行全量单测、类型、文档与包验证。当前只本地完成，不推送/部署/npm。
